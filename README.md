# domotz-deployment

Custom Domotz deployment imaged on Protectli boxes running Ubuntu, for network monitoring, plus **dynavlan**, a self-configuring VLAN provisioning tool that auto-discovers active VLANs on the trunk and brings them up with DHCP (no SSH, no hand-edited YAML).

- `docs/dynavlan-PRD.md` -- dynavlan product requirements (the primary deliverable).
- `docs/deployment-guide.md` -- the manual Domotz-on-Ubuntu provisioning runbook dynavlan builds on.
